# VocabTrainer

交互式背单词工具，纯前端单文件应用，双击 `index.html` 即可使用。

## 功能

### 📥 导入单词
- 拖入/选择类似「基础练习」的 HTML 文件，自动解析提取单词
- 粘贴 HTML 源码解析
- 预置「雅思词汇 List 7」（71 词）

### 🔍 筛查模式
- 快速浏览单词，标记「认识」或「不认识」
- 支持键盘快捷键（1=认识，2=不认识）
- 筛选出需要重点学习的生词

### 📖 背生词模式
- 只针对「不认识」的单词集中练习
- **卡片**：点击/空格翻卡看释义
- **测验**：4 选 1 选择题
- **列表**：生词表，支持搜索

### 💾 数据持久化
- 所有进度自动保存到浏览器 localStorage
- 支持多词库管理

## 快捷键

| 模式 | 快捷键 | 功能 |
|------|--------|------|
| 卡片 | 空格 | 翻卡 |
| 卡片 | ← → | 切换单词 |
| 卡片 | 1 | 标记已掌握 |
| 筛查 | 1 | 认识 |
| 筛查 | 2 | 不认识 |
| 测验 | A/B/C/D | 选择答案 |
| 测验 | Enter | 下一题 |

## 技术
- 纯 HTML/CSS/JS，无需构建工具
- Vanilla JS DOM 渲染
- localStorage 数据存储
- 暗色/亮色主题
